# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.1.12] - 2026-10-07

### Fixed
- The withdrawal, confirm, status and success pages now have a single H1. The theme page title block is removed on these pages instead of only being hidden.
- Storefront colours follow the store palette: text #171717, muted text #525252, borders #E5E5E5, field borders #D4D4D4, required marker #B91C1C, notices and status badges use the brand, success, warning and danger colours.
- Form fields are 46px high with 16px text, matching the other storefront forms.
- Luma: the notes under the withdrawal form (excluded products, return shipping, refunds) use the muted text colour #525252 instead of the general paragraph colour.
